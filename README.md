# Arsenic-SBX
**REQUIRES** Arsenic Server toggle on (https://github.com/MinePlayer16/arsenic).

This dylib, injected into the client's app, grants it a sandbox escape without needing to run DarkSword's kernel exploit multiple times.

Arsenic requests and sends over a sandbox extension token for the injected app's PID.

Tested on Filza, Fila and Filos (Works on LiveContainer too)
